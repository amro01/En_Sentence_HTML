📖 使用指南

📝 基本操作 — 日期自动填充当天；点击"添加卡片"创建练习项，填写英文段落与中文翻译；可点击"删除此条"移除卡片。

✨ AI 智能生成 — 展开顶部「⚙️ AI 助手配置」，填写 OpenAI 兼容的 API Base URL、API Key 与模型（默认智谱 GLM-4.7-Flash），点「🔌 测试连接」确认可用。之后在每张卡片点「✨ AI 智能生成」，会根据中文生成 2~3 个正确表达与起手式；勾选「同时生成同伴抢答错句」还会生成错句、3~4 个意群胶囊和温和讲解，并自动切换为陷阱卡。配置只存本机 localStorage，API Key 不会写进下载的练习页。

🔄 排序与说明框 — 点击卡片左侧 ↑/↓ 调整顺序（首尾按钮自动禁用）；点击"添加说明框"插入解释文本，支持基础 HTML 标签。

🎤 多角色朗读 — 英文中用 M: Hello! 或 Wang Mei：你好 格式标记角色，朗读时自动匹配男/女声。支持 M(男)、F/Wang Mei/Jenny/Amy 等(女)、Li Ming/Tom/Jack 等(男)。

⭐ 评价与勋章 — 🎧 每完整听一次点亮一个耳机图标，满 3 个卡片变金色；⭐ 思考达标 或 打磨≥3 次之一即可获五星；🌙 所有句子在半速内完成且重听≤1 次获 6 月亮；🧹 点击"清空记录"重新挑战。

🎭 同伴抢答 — 被标记的卡片会出现一位随机同伴（小明 / 小熊 / 青蛙 / 玲玲），把句子切成 3~4 个意群胶囊。陷阱卡里同伴会说错一句，孩子点出错误意群即可；普通卡里同伴说对了，孩子点「👍 这句没问题！」即可。辨析通过后，同伴气泡收起成右上角小徽章。

🚀 起手式布局 — 所有卡片统一显示清晰中文；阶段 1 通过后，左侧出现句首起手式（前 2~3 词），右侧整句默认隐藏。孩子选定起手式后点击右侧槽位，整句淡入并朗读。

📂 成绩反馈监控目录 — 在第 5 节点「📂 设定/切换成绩目录」选择存放勋章 TXT / 错题包 JSON 的文件夹。生成器会把目录授权存进 IndexedDB，刷新页面自动恢复；每天只需把新勋章丢进该目录，点「🔄 立即扫描更新」即可自动解析全部反馈、按 Practice_ID 去重并合并复习进度。不支持目录授权的浏览器可用「选择文件夹（降级）」或直接拖拽整个文件夹到监控区。

🎯 智能推荐复习 — 推荐分综合手动红标、遗忘曲线到期、历史失败次数与毕业观察期，给出 0~100 分排序与 🔴 极度生疏 / 🟠 到期复习 / 🟡 观察中 / ⭐ 手动重点 标识。「填入推荐 3 句 / 5 句」一键成卡；「批量自选复习」可自由勾选后填入。复习句若是同伴错句，会自动回填对照英文并勾选同伴抢答。连续 2 次快速通过自动毕业，避免无限堆积。

🔁 生疏句循环复习 — 练习页静默自动判弱（孩子端无「错题/复习」标签），完成后家长在页面底部「家长审计」区勾选圆点手动标记；领取勋章时下载的 TXT 命名为 YYYY-MM-DD_孩子名_PracticeId_勋章.txt，放入成绩监控目录即可被自动追踪。也仍支持复制 / 回传 / 导入错题包。

🔒 家长审计 — 启用家长锁后，重置需数学验证；系统自动记录首轮测试快照和重置次数，生成勋章时强制附加家长审计数据；思考时间<0.5秒触发异常标记，<1.0秒无法获得6月亮评价。

📦 生成与下载 — 点击"生成练习网页"预览代码，点击"下载 HTML 文件"保存为独立网页。
